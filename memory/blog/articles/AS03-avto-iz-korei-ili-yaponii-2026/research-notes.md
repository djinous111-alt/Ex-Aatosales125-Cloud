## action_outline
1. Записать задачу: себе на годы / с перепродажей; город/регион эксплуатации.
2. Выбрать руль: левый обязателен → смотреть Корею первым; правый ок (ДВ) → можно Японию.
3. Зафиксировать потолок мощности (ориентир льготы физлица ~160 л.с.) и возраст/сегмент — **до** поиска лотов.
4. Собрать 1–2 кандидата из Кореи и 1–2 из Японии в одном бюджете «под ключ», не по цене объявления.
5. Запросить у Авто-Сейлс два расчёта под ключ через каталог (без самодельных «калькуляторов пошлин» в голове).
6. Для корейского кандидата: проверка истории/осмотра до депозита (связка с гайдом Encar/Carhistory).
7. Для японского: разобрать аукционный лист с менеджером, понять оценку и дефекты.
8. Свести таблицу: руль / мощность / смета / срок / риск перепродажи → выбрать сторону.
9. Только после этого — депозит и заказ логистики через Владивосток; дальше — растаможка/СВХ по отдельным чек-листам сайта.
