## action_outline

1. Открыть карточку лота и найти **код кузова** (не только название модели) – без кузова дальше не идём.
2. Определить тип: мягкий (электромотор только помогает) / полный / PHEV / EV / e-POWER – если машина умеет ехать на электротяге сама, для прямого вывоза это стоп.
3. Сверить объём ДВС: нужно **≤1,9 л**; мягкий гибрид с 2,0 л всё равно красный флаг по объёму.
4. Сверить кузов с ориентировочным списком мягких (Suzuki Solio/Swift/Hustler/Wagon R…, Mazda Flair, Dayz, Delica D:2/Mini, Fit/Insight/CR-Z нужных кузовов) – список как шпаргалка, не как догма.
5. Прочитать аукционный лист целиком: оценка, схема кузова, пробег, рукописные пометки инспектора – не только фото "красивого ракурса".
6. Прогнать красные флаги: Prius/Aqua/полный e:HEV, Outlander PHEV, Leaf/EV, Note e-Power, мотор >1,9 л, неясный кузов.
7. Если хоть один пункт "не уверен" – **не вносить депозит**; отправить ссылку на лот на сверку (каталог / Telegram @avtosales125, Владивосток).
8. Только после зелёного вердикта по вывозу обсуждать полный расчёт под ключ (без самодельных сумм пошлин из статей).
9. Зафиксировать для себя итог одной фразой: "мягкий + кузов X + ≤1,9 л + лист ок" или "стоп, ищем другой лот".

## Чек-лист из 10 пунктов до заказа (для Writer → H2)

1. Есть полный аукционный лист, не только превью фото.
2. Выписан код кузова.
3. Тип гибрида определён (мягкий / полный / PHEV / EV / e-POWER).
4. Объём ДВС ≤1,9 л.
