## action_outline
1. Выписать из карточки Encar: модель, год, объём, мощность (л.с. и/или кВт), VIN если есть — **ещё не платить**.
2. Найти мощность в **кВт** в фото шильдика моторного отсека / техпаспорта / сертификата производителя (не в маркетинговом тексте).
3. Сравнить с порогом: ≤117,68 кВт включительно — зона «до ~160 л.с.»; от 117,69 кВт — считать коммерческий сценарий.
4. Если в карточке 158–162 л.с. или только л.с. без кВт — поставить красный флаг и запросить уточнение у продавца/посредника **до депозита**.
5. Проверить тип силовой установки: обычный ДВС / параллельный гибрид / e-Power·EV (другой порог) — не смешивать правила.
6. Параллельно глянуть объём и условие «личное пользование» — мощность не единственный фильтр льготы.
7. Пройти чек-лист из 8 пунктов и сохранить скрины карточки + шильдика.
8. Запросить в каталоге Авто-Сейлс расчёт утильсбора по конкретной комплектации (не по чужому онлайн-калькулятору как «истине»).
9. Депозит — только после «кВт сверены» или подтверждения расчёта в чате.

### Чек-лист до депозита (8 пунктов — каркас H2)
1. Есть кВт из документа/шильдика, не только л.с. с Encar.  
2. Сверка с 117,68 / 117,69 кВт сделана.  
3. Фото шильдика совпадает с карточкой (нет «магического» округления).  
4. Комплектация/модификация по VIN не перепутана с соседней (180+ л.с.).  
5. Тип двигателя учтён (ДВС vs EV/последовательный гибрид).  
6. Объём двигателя не выбивает из льготных условий сам по себе.  
7. Понятен режим ввоза: личное пользование vs коммерческий.  
8. Есть расчёт/консультация по лоту до оплаты задатка.
