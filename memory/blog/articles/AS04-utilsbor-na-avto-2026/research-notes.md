## verified_facts_for_article
Каждая цифра ниже — только со ссылкой; Writer не раздувает коммерческую сетку.

1. Базовая ставка легковых M1: 20 000 ₽ × коэффициент (ПП 1291 / разъяснения калькуляторов со сверкой на 2026). Источники: utilsbora.ru/postanovlenie-1291, calcup.ru, azway.ru — accessed_at 2026-11-01.
2. ПП РФ № 1713 от 01.11.2025 вступает с 01.12.2025, меняет коэффициенты и добавляет мощность в кВт для M1. Источник: consultant + nalog.gov.ru.
3. Редакция ПП 1291 на КонсультантПлюс: ред. от 06.02.2026. Источник: consultant cons_doc_LAW_156832.
4. Льготный контур физлица: коэффициенты 0,17 / 0,26 → 3 400 ₽ (до 3 лет) и 5 200 ₽ (старше 3 лет) при соблюдении условий личного пользования, объёма ≤ 3 000 см³, мощности ≤ 160 л.с. (117,68 кВт). Источники: azway, utilsbora FAQ, e1.ru.
5. Условия льготы одновременно: физлицо, для себя, регистрация на себя, не более одного льготного ввоза в 12 месяцев, без продажи раньше 12 месяцев с даты ТПО (иначе доплата до коммерческого). Источники: azway, utilsbora FAQ / сноска <7>.
6. Страна покупки (Корея / Китай / Япония) при прямом оформлении в РФ сама по себе ставку не меняет — меняют характеристики ТС и статус плательщика. Источник: azway FAQ «одинаковый?».
7. Для электромобилей и последовательных гибридов берётся максимальная 30-минутная мощность; для прочих гибридов — сумма ДВС + 30-минутной мощности электромотора (сноска <2>). Источники: utilsbora постановление-1291, azway.
8. Порог льготы для EV по обзорам 2026: около 80 л.с. / 58,84 кВт 30-минутной мощности. Источник: utilsbora FAQ, utilsbor-calc.ru.
9. Проект единой формулы для физлиц из ЕАЭС с датой 01.04.2026 не вступил: Минпромторг 31.03.2026 — на согласовании. Источник: interfax.ru/russia/1081241; статус «нет постановления» подтверждают отраслевые разборы на сентябрь 2026.

## action_outline
1. Выписать из карточки авто (Encar / аукционный лист / китайский прайс) возраст, объём, заявленную мощность и тип двигателя — отдельно пометить «это реклама, не документ».
2. Определить свой статус: физлицо для личного пользования или коммерческий/перекупный сценарий (от этого зависит льгота).
3. Проверить пороги льготы: объём ≤ 3 000 см³, мощность ≤ 160 л.с. (117,68 кВт) для ДВС/параллельных гибридов; для EV — документальная 30-минутная мощность и её порог.
4. Для гибрида/EV заранее спросить у подборщика, откуда берётся мощность в расчёте (не складывать «пиковые» цифры из баннера).
5. Не путать страну покупки (Корея/Китай/Япония) с формулой утильсбора и не путать прямой ввоз через РФ с схемами ЕАЭС.
6. Сверить, что читали про «1 апреля 2026», с актуальным статусом проекта — не закладывать непринятые правила.
7. Собрать 5 полей чек-листа и отправить на расчёт в каталог Авто-Сейлс / уточнить в Telegram до оплаты депозита.
8. Только после свежей цифры по лоту принимать решение «брать / искать версию слабее 160 л.с. / отказаться».
