## action_outline
1. Открыть Encar (или зеркало через подборщика) и искать именно Avante / 아반떼, поколение CN7 — не путать с новостным CN8 2026.
2. Выписать из шапки лота слово комплектации: Smart / Modern / Inspiration (и отдельно N Line, если есть).
3. Пройти фото-чек: фары (галоген / LED MFR / projection LED), размер дисков, кластер 4,2″ vs 10,25″, материал сидений, кнопки подогрева/вентиляции, smart key.
4. Сверить заявленные опции в карточке с фото; спорные пункты (Bose, memory seat, rear heat, 360°) пометить «нужен осмотр».
5. Открыть страховую историю: стоп при тотале/утоне/утоплении; крупные выплаты разобрать до депозита.
6. Открыть лист осмотра: X = замена, W = рихтовка/сварка; «무사고» не отменяет X/W на дверях и крыльях.
7. Проверить особые отметки: 렌트 (прокат), лизинг, коммерция — при сомнении вычеркнуть лот.
8. Уточнить дату производства (не только «식» регистрации) и мощность в кВт/л.с. как стоп-флаг до расчёта — без таблиц утиля в статье.
9. Скриншотнуть цену и ID лота; собрать 2–3 кандидата, а не один «красивый» Modern.
10. Если опции и история не сходятся или корейский текст не читается — отдать короткий список в подбор Авто-Сейлс (Владивосток), а не слать депозит по названию пакета.
11. До перевода депозита пройти итоговый чек-лист из 12 пунктов (ниже для Writer).
12. После зелёного чек-листа — запросить персональный расчёт под ключ в каталоге / Telegram (без выдуманных сумм в тексте).

### checklist_12_for_writer
1. Имя в поиске: Avante CN7 (не Elantra US-only фильтр).
2. Trim в шапке записан.
3. Свет сверен с фото.
4. Кластер сверен с фото.
5. Подогрев/вентиляция 1 ряда: есть / нет.
6. Smart key / кнопка Start: есть / нет.
7. Экран 8″ vs 10,25″ / panorama.
8. Страховка п.4 чистая.
9. Выплаты п.5 понятны.
10. Схема без X/W на силовом каркасе (при W на навеске — осознанный риск).
11. Нет проката/лизинга (или риск принят письменно).
12. Цена и ID сохранены скрином до депозита.
