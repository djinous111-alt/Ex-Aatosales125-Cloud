## action_outline
1. Открыть карточку лота и выписать: марка, модель, код кузова, объём ДВС, есть ли пометка Hybrid / HYBRID MG/MX/MZ / e:HEV / e-Power / PHEV.
2. Проверить объём: для прямого вывоза из Японии ДВС должен быть ≤1,9 л (1900 cc); больше – стоп на прямом маршруте.
3. Определить тип: soft/mild (помощник без чистого электрохода) vs полный гибрид vs последовательный (e-Power) vs PHEV/EV.
4. Если не mild – считать лот непроходным для прямого экспорта из Японии в РФ (нужен другой маршрут или отказ).
5. Если mild – сверить код кузова со свежим рабочим списком (Solio MA37S/MA36S, Swift ZC53S/ZD53S, Hustler MR52S/MR92S, Spacia MK*, Xbee MN71S, Dayz BR06, Delica Mini B33A/B34A и т.д. по Newsvl) – модель без кода не считать "разрешённой".
6. Прочитать аукционный лист: оценка, замечания, сверка номера кузова; красные флаги кузова/рамы – отдельный стоп даже для проходного гибрида.
7. Зафиксировать мощность из каталога комплектаций/листа; для утильсбора в РФ понять тип установки (суммарная vs 30-минутная), но не считать сумму самому по статье.
8. Запросить у Авто-Сейлс (каталог / Telegram) подтверждение: вывоз ок + ориентир оформления до ставки.
9. Депозит и ставка – только после "да" по пунктам 2–8; иначе стоп.
10. После покупки держать пакет: лист, инвойс, данные кузова – пригодятся на СВХ Владивосток.
